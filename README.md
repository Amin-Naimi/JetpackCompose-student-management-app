# Jetpack Compose Student Management App

A student management application developed using Jetpack Compose. It features CRUD operations, Room Database for local persistence, and Jetpack Navigation for seamless screen transitions.

## Features

- Add new students with details like name and age.
- Edit existing student information.
- Delete students from the list.
- View all students in a structured list.
- Navigate between screens using Jetpack Navigation.

## Technologies Used

- **Jetpack Compose** – modern UI toolkit for Android
- **Kotlin** – programming language
- **Room Database** – local data persistence
- **Jetpack Navigation** – screen management and transitions

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/jetpack-compose-student-management-app.git
   ```

2. Open the project in **Android Studio**.

3. Build and run the app on an emulator or Android device.
